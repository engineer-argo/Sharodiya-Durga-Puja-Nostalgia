🪔 Durga Puja — Sharodiya Nostalgia

A cinematic, immersive single-page web experience inspired by Bengali Durga Puja, Kolkata's festive nights, and the nostalgia of Sharodiyo.

A visually rich nostalgic website that brings together pandal hopping, dhaak, dhunuchi, shiuli flowers, autumn skies, Puja lights, Bengali typography, music, and Bijoya memories into one interactive digital experience.

✨ Live Experience

Durga Puja — Sharodiya Nostalgia

The project is designed to feel like a digital memory of walking through Kolkata during Puja at night — warm lights, crowded pandals, dhaak beats, incense smoke, and that bittersweet feeling when Bijoya arrives.
